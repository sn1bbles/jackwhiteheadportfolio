Gopher Game

Learning how to design a game with JS / HTML / CSS

The Gopher Game project was where I really started to see the web come alive. We had to design a game using HTML, CSS, but mostly JavaScript, and honestly, it was a blast. I ended up making this kind of silly gopher game – it just felt like the right idea at the time. It was so cool to take an idea and actually make it interactive on a screen. This project was a big moment for me because it was the first time I really felt like I was creating something playful and engaging with code. It definitely sparked my interest in making things move and react on the web.
