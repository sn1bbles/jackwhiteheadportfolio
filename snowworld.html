SnowWorld Recreation

Rebuilding a website with strict coding rules.

In my second year, a core assignment involved selecting a website and rebuilding it while adhering to strict coding standards. For this task, I chose the SnowWorld website. The project demanded a focus on creating a fully responsive design, utilizing semantic HTML for clear structure, and ensuring accessibility for all users

This assignment, though challenging (frustrating) at times, proved to be a significant learning curve in developing robust coding practices. It underscored the critical importance of code hygiene writing clean, well-organized, and accessible code.
